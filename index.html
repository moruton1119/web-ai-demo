Browser-only AI · No Server

ブラウザの中で動くAI実験場

このサイトのAIは、すべてあなたのPCのブラウザの中だけで動きます。 サーバーに計算を任せない静的なサイトなので、入力した内容が外部に送られることはありません （初回のみモデルファイルをHugging Faceから直接ダウンロードします）。

💬

ウェブLLM チャット

llama.cpp をブラウザ内で動かす「naidan」ベース。好みのGGUFモデルを読み込んで、ローカルだけでLLMと会話できます。

naidan / llama.cpp WASM+WebGPU 🖼️

ウェブ画像生成

SD-Turbo をWebGPUで実行。プロンプトを入れると数ステップで512×512の画像を生成します。重い計算はすべてあなたのGPUで。

SD-Turbo / ONNX Runtime Web + WebGPU

利用上のメモ

  • PC専用です。スマホ・タブレットからはご利用いただけません
  • 対応ブラウザ: Chrome / Edge（WebGPU対応）。Firefox 141+・Safari 26+でも動作するはずです
  • 初回起動時のみモデルのダウンロードがあります（画像生成: 約2.4GB / LLM: モデルによる）。2回目からはブラウザキャッシュで高速起動
  • 元技術: naidan (nwtgck氏)・Microsoft SD-Turbo example
